# Run python interpreter in command line

- Use one of the following commands in command line: `py`, `python` and `python3`
```cmd
C:\Users\User> py
>>>
```

ℹ️: If you see `>>>` it means that you are now writing in the interpreter.

- Execute code inside of a interpreter
```cmd
>>> print("Hello World")
Hello World
```
- Close python interpreter by using `exit()` function
```cmd
>>> exit()
C:\Users\User>
```
