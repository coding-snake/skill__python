# Run python scripts from the command line

Python scripts are written with an extenson `.py`, for example it could be something like this

_hello_world.py_
```py
print("Hello World")
```

You can execute them by using one of the following commands: `py`, `python` and `python3`.

```cmd
C:\Users\User> py hello_world.py
Hello World
```
